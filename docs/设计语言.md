# EnvSwitch 设计语言

> 与 [design/index.html](../design/index.html) 一一对应；前端 CSS 变量直接搬运本文件 token，改视觉先改设计图再同步代码。

## 1. 方向

- 产品：Windows 开发者环境版本切换台，查看 / 安装 / 卸载 / 切换，全程免命令。
- 气质：冷静、精确、仪表感。
- 世界：暗色机房与设备架仪表面板——冷静的石墨底、发丝线分格、等宽数字、状态指示灯。
- 时刻：总览页「当前环境控制台」六张仪表卡；详情页激活版本行。
- 签名：每个工具行首的状态指示灯，颜色只表达真实探测结果。

## 2. 色板（石墨冷灰阶 + 单一信号绿）

```css
:root {
  /* 面：三阶抬升，靠色差与发丝线表达层级，不用阴影 */
  --bg:        #0D0F12;   /* 窗口底 */
  --surface:   #14171B;   /* 面板 */
  --raised:    #1A1E24;   /* 卡片 / 行 hover */
  --overlay:   #20252C;   /* 弹层、下拉 */

  /* 线：所有边框 = 发丝线，前景色 8% */
  --hairline:  rgba(233,236,239,.08);
  --hairline-strong: rgba(233,236,239,.14);

  /* 文字三角色 */
  --ink-1: #E9ECEF;       /* 主文本、数值 */
  --ink-2: #9BA3AC;       /* 次文本、标签 */
  --ink-3: #626C76;       /* 弱文本、meta */

  /* 点缀：信号绿，一屏至多一处主按钮用它 */
  --accent:       #3FBFA8;
  --accent-ink:   #A8E6DA;  /* 暗底上的 accent 文字，对比 ≥ 4.5 */
  --accent-deep:  #143430;  /* accent 底上的深文本区 */

  /* 语义（压低饱和度，只在表达状态时出现） */
  --ok:     #3FBFA8;
  --warn:   #D9A34A;
  --danger: #E06C6C;

  /* 灯（签名元素） */
  --lamp-off:   #3A424B;
  --lamp-idle:  #626C76;
}
```

规则：背景永不带色相；accent 不做渐变字、不做辉光；深色下的立体感 = 面阶 + 发丝线，窗口浮层允许一个中性软阴影。

## 3. 液态玻璃（克制使用，只允许两层）

1. **顶栏**（48px）：`background: rgba(13,15,18,.72); backdrop-filter: blur(20px) saturate(1.2);` 底边 1px 发丝线。
2. **托盘浮层 / 下拉菜单 / 对话框遮罩上的弹层**：`rgba(26,30,36,.78) + blur(24px)`，1px 发丝线边框，顶内高光 `inset 0 1px 0 rgba(255,255,255,.06)`，圆角 12，中性阴影 `0 16px 40px rgba(0,0,0,.45)`。

主内容卡片一律实心面板，不玻璃——「略微」即两层。

## 4. 字体与排版

```css
--font-ui:   "Segoe UI Variable Text", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif;
--font-num:  "Cascadia Mono", "Consolas", monospace;   /* 版本号、大小、速度、时间戳 */
```

- 全部句子式大小写；无大写拉开字距的标签；无斜体强调。
- 字号阶梯（4px 基）：11 / 12 / 13 / 14 / 16 / 20 / 28；字重仅 400 / 500（600 只给窗标题级）。
- 层级靠尺寸 + ink 色阶，不靠字重堆。版本号一律 `font-num; font-variant-numeric: tabular-nums`。
- 数字格式全窗统一：大小 `1.2 GB / 482 MB / 96 KB`，速度 `7.4 MB/s`，时间 `11-18 14:03`。

## 5. 栅格与密度

- 4px 网格。页边距 24；卡片内边距 20；行高（列表）44；导航行 34、间距 2；分组间距 24、组内间距 8。
- 侧栏 240px；内容流式，上限 1440。
- 圆角嵌套：窗口 14 / 面板 12 / 卡片 10 / 控件 8 / 灯与点 999；内圆角 = 外圆角 − 内边距且 ≥ 4。
- 图标：一套线性图标，18px、1.5 描边、随文字色；工具各有几何标识（node 六边形、npm 立方、pnpm 三层方块、yarn 球线、python 双片、go 箭头），禁止 emoji。

## 6. 组件规范

| 组件 | 规范 |
|------|------|
| 状态灯 | 8px 圆点；绿=已激活就绪，灰蓝=已装未激活，暗=未装，琥珀=有更新，红=PATH 冲突。仅颜色变化，无脉冲动画 |
| 仪表卡（总览） | 工具图标+名（ink-2,13px）→ 灯+版本（ink-1,20px mono）→ 来源徽标；hover 才出现「切换 ▾」 |
| 徽标 | 纯文本小号：`store` `nvm` `system`；等宽 11px，ink-3，发丝线描边胶囊 |
| 列表行 | 高 44；灯/版本/来源/大小（右对齐等宽）/操作 hover 显现；激活行 = raised 面 + 左 2px accent 条 |
| 进度行 | 安装中版本行内嵌 2px 进度线（accent），右侧速度+取消；取消为文字按钮 |
| 主按钮 | accent 底 + `#0D0F12` 深色文本；次按钮 = raised 面 + 发丝线；文字按钮 = ink-2 hover ink-1 |
| 下拉/托盘 | 玻璃浮层（§3.2）；当前项左侧灯亮 + 右勾（18px 线性） |
| 危险操作 | 卸载无二次弹窗，行内「确认删除?」替换按钮组（两步即达，不打断）；reset PATH 走对话框 |
| 空态/离线 | 灰灯 + 一句 ink-3 说明 + 一个动作；不画插画 |

## 7. 动效

- 一个缓动 `cubic-bezier(.2,0,0,1)`；时长：反馈 120ms / 进入 180ms。
- 允许的动效：视图切换 8px 上移淡入；激活行版本数字切换做一次 6px 位移过渡；进度线宽度；弹层从触发点淡入升起。
- 禁止：常驻循环动画、缩放弹跳、hover 移动超过 2px、动画化布局属性（宽高 margin）。

## 8. 文案

- 中文为主，界面语句短、直陈：「当前使用 22.22.0」「切到 20.19.0」不写「一键极致切换！」。
- 数字带比较基准：「比当前小 18 MB」；状态陈述事实：「PATH 中 nvm 的 node 在前列」。
- 错误格式：`<发生了什么> · <下一步>`：「校验失败 · 下载文件与官方哈希不符，已自动重试 1 次」。
