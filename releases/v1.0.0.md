# EnvSwitch v1.0.0

首个正式版本。把 Windows 上散落的 node、python、go、java 等开发工具版本统一收进独立版本库，界面上点一下就切换；不改系统 PATH、不需要管理员权限。

## 本次新增

- **桌面端与 CLI**：Wails v2 + Vue 3 桌面应用（环境总览、工具详情、系统设置三视图，自绘标题栏、侧边栏、明暗主题），以及共用同一套核心逻辑的 `envs.exe` 命令行。
- **版本切换引擎**：独立版本库（`store\<工具>\<版本>`）+ junction 重指向，切换只改一个目录链接，毫秒级生效；PATH 仅在首次启用时写入一次，之后不再改动。
- **17 款工具**：覆盖运行时（node/python/go/Rust/PHP/Deno/Bun）、包管理（npm/pnpm/yarn/uv）、JVM 与 .NET（JDK/Maven/Gradle/.NET SDK）、云原生（kubectl/Terraform），各自独立管理版本与缓存。
- **安装流水线**：选源下载、断点续传、sha256/integrity 校验、解包落位、版本号冒烟；主源失败自动切备用源，校验不符直接失败删件。
- **镜像与网络**：默认走国内源（npmmirror、golang.google.cn 等），node / npm / pnpm / yarn 可在设置页直接切官方源，python / go / maven 用 `envs config set mirror.<工具> <源>` 指定，另支持 GitHub 代理前缀。
- **与 nvm 等共存**：对 nvm-windows 只读识别，已装版本可直接切换，零下载且不删他人目录；`envs doctor` 可解析 PATH 里实际胜出的可执行文件。
- **系统托盘与自启**：托盘右键按工具列出已装版本，点一下即切；开机自启走 HKCU Run，全程免管理员。
- **exe 热更新**：GitHub 静态清单驱动，下载校验后自替换，保留 `.old` 上一版并带心跳自检，异常可一键回滚。
- **安装包**：CI 自动产出 portable zip（附 SHA256SUMS）与 NSIS per-user 安装包。

## 适用范围

Windows 10 1809+ / Windows 11，x64。首次运行需要 WebView2（安装包会引导安装）。

完整命令与机制见 [README](https://github.com/HUIdada1/EnvSwitch#readme)。
