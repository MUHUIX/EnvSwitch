# EnvSwitch v1.0.1

首个可下载的正式版本。v1.0.0 的代码本身没有缺陷，但发布流水线在安装包这一步连续失败，线上始终没有产出任何二进制；这一版把流水线修通，便携包与安装包一起提供。

## 本次修复

- **安装包构建**：CI 此前从 SourceForge 的 `/download` 重定向页取 NSIS，在 Windows runner 上秒失败（重定向被拦）。改为 `downloads.sourceforge.net` 直链下载，解包前先校验文件体积，失败则回落到 Chocolatey 安装，不再依赖 runner 预装环境。
- **不再静默放行**：安装包构建从「失败也继续」改为硬性步骤，并在编译后断言 `EnvSwitch-Setup-<tag>.exe` 确实存在。宁可整次发布失败，也不发出缺安装包的残缺 Release。

## 下载

| 文件 | 用途 |
| --- | --- |
| `EnvSwitch-Setup-v1.0.1.exe` | 安装版，per-user 装到 `%LOCALAPPDATA%\Programs\EnvSwitch`，免管理员，装完可选开机自启 |
| `EnvSwitch-win-x64.zip` | 便携版，`EnvSwitch.exe` + `envs.exe` 解压即用 |
| `SHA256SUMS.txt` | 便携包校验值 |

功能与 v1.0.0 完全一致（17 款开发工具的版本管理、junction 切换、托盘、exe 热更新），完整清单见 [v1.0.0 说明](https://github.com/HUIdada1/EnvSwitch/blob/main/releases/v1.0.0.md)。
