# EnvSwitch v1.3.0

这版能把 nvm 收编进来的版本也直接卸载了，修掉热更新跨盘失败、「托盘退出一次后点 × 就永久直接关程序」等问题，并把明亮主题按 WCAG AA 重做了一遍。

## 新增：卸载 nvm 收编的版本

- 卸载按钮不再只对「版本库」里的版本开放：nvm 收编进来的版本同样可卸载；系统 PATH 探测到的行仍是只读（不在受管目录里，删它等于删你的系统环境）。
- 真删目录前有一整套安全托底：目录必须真实存在且是目录、必须严格位于 nvm 根目录第一层、目录名必须符合 nvm 版本命名、本身不能是 junction（否则 `RemoveAll` 会删穿到别处）——任何一条不满足就拒删并说明原因。
- 卸载当前生效版本会自动摘掉激活链接并切到剩余最新版本；只剩最后一个可卸载版本时按钮禁用，避免把本机删到无版本可切。
- 版本写法托底：`v22.22.0` 这类带前缀的写法先归一化再找版本库，不会因为写法不同被误推到 nvm 分支。

## 问题修复

- **热更新报「放置新版本失败」**：更新包暂存在 `%LOCALAPPDATA%`（C:\）而程序装在别的盘时，`os.Rename` 直接报 `ERROR_NOT_SAME_DEVICE`。现在同卷仍走原子重命名，跨卷退化为「复制到目标同目录临时文件 → 删旧 → 换名就位」，中途任何一步失败只留下一个 `.incoming`，不会留半个可执行文件在原位。已补跨盘回归测试。
- **热更新后新版本起不来**：`ApplyUpdate` 之前没标记真退，开着「关闭时最小化到托盘」时旧进程只是隐藏，新进程拿不到单实例锁，表现为静默失败甚至回滚。
- **托盘退出一次后，点 × 变成直接关程序**：旧实现把 `closeToTray=false` 写进了设置文件。改成只在当前进程生效的一次性内存旗标，设置值不再被退出动作污染。
- **卸载后版本还赖在列表里**：删完目录没清系统环境探测缓存，60 秒内刚删掉的版本会以「系统环境」行重新出现（nvm 收编版本尤其容易命中）。
- **切换工具后右栏残留上一个工具的内容**：官方版本列表、搜索关键字、索引报错、安装进度都会残留。现在换工具先清视图状态再重载（后台安装任务不受影响，完成提示仍有 toast 兜底）。
- **总览快捷切换弹层被长版本号顶破**：弹层定宽、来源标签不参与收缩、版本号走省略号，不再冒出横向滚动条。

## 明亮主题重做

- 全套前景色按 WCAG AA 校准：正文三级灰对白底约 19:1 / 9.6:1 / 5.9:1，12~13px 小字全部过 4.5:1；`--ok` 由 3.3:1 压到 4.6:1，`--warn` 在白底与同色底纹上都稳过。
- 背景分层（外圈冷灰 → 面板纯白 → 悬停更深）、分隔线加重，不再是一片死白没有层次。
- 状态色套件（`--ok/warn/danger/info` 的 `-bg` / `-line`）与弹层阴影色抽成 token，替换原先散落在各视图里的暗色硬编码 rgba——暗色观感不变，明亮主题自动跟上。
- 关闭按钮悬停态在白面板上原本只有 2.3:1 对比，明亮主题改为浅红底 + 深红笔画。
- 明亮主题用户冷启动不再先闪一屏暗色：`index.html` 在样式绘制前按已存偏好改写一次 `data-theme`。

## 侧栏与动效

- 侧栏折叠态的分组头不再是空白分隔线：改成居中的分组代表图标（运行时 `</>`、包管理立方体、企业运行时公文包、云原生云朵）；分组被收起时图标压暗并在右下角点一个状态点。
- 更新提醒红点、侧栏红点、toast 状态点统一为「雷达扩散」语言：点本体不动，同色圆环原位向外淡出；开启「减少动态效果」时全部关闭。
- 界面字体改为思源黑体优先（本地家族名四个别名并列托底），机器上没装时自动回退微软雅黑，不会掉到宋体。
