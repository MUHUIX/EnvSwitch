# EnvSwitch v1.4.0

这版把「装在哪、用哪个」变成看得见也改得动：版本库可以整体换盘，JAVA_HOME 这类环境变量交给工具托管，每个工具的安装位置与 PATH 来源都在详情页摊开。

## 新增：版本库换位置

- 设置页「本地存储」可以直接改版本库根目录，整棵版本树一起搬，而不是让单个版本散落在各个盘。
- 目标必须是空目录；UNC 路径、盘根、`current`/`bin` 内部、home 下非默认目录一律拒绝，避免搬到一半才发现路径不合法。
- 同盘走重命名（瞬间完成），跨盘走复制 + 文件数与字节数核对；失败会删掉本次写入的新目录并保留旧库，配置一个字节都不改。
- 迁移期间安装、切换、卸载由后端读写锁挡住，不会出现「搬到一半还在装版本」。
- 已知限制：跨盘迁移时进程被强杀，目标目录会留下半份副本（配置未改、旧库完整），清空目标目录后可重试；迁移过程不可取消。

## 新增：环境变量托管

- `JAVA_HOME` / `GOROOT` / `DOTNET_ROOT` / `MAVEN_HOME` / `M2_HOME` / `GRADLE_HOME` 六个变量可按工具开启托管，切换版本后自动指向当前版本。
- 只写用户级 `HKCU\Environment`，改前备份原值；关闭托管或该工具版本被删空时，自动还原成原来的值。
- java/go/maven/gradle 的 `current` 链接指向版本下的 `bin`，而 `JAVA_HOME`/`GOROOT` 要的是版本根 —— 托管值会自动上提一级，不会出现 `JAVA_HOME=...\bin` 这种错配。
- 写入后广播环境变更；已经开着的终端需要新开一个才生效。

## 新增：安装位置与环境配置

- 工具详情顶部直接显示当前版本的真实路径；本机版本列表改成两行式，第二行常显安装目录，点一下即复制。
- 新增「安装位置」四格卡：版本库根、本工具目录、激活链接（含指向目标）、新版本安装模板，每格都能复制或直接在资源管理器打开。
- 系统 PATH 探测到的工具标明来源，只读；远程版本行会给出这次安装的具体落点。
- 新增「环境配置」卡：PATH 注册项、相关环境变量、命令 shim 是否就位，只读展示，方便排查「装了却不生效」。

## 安装前先看落点

- 点安装先弹确认层，写清这次要装到哪；可在弹层里直接「更改版本库位置」，迁移完成后接着装。

## 软件更新

- 更新说明按要点分条列出，默认只显示 5 条，其余可展开；标题符号、表格与下载清单不再混进正文。
- 「立即更新」固定在更新卡片右下角，宽度固定，不再被长说明挤到变形或换行。
- 新增整条流程的进度显示：下载百分比与速度 → 校验解包 → 替换程序文件 → 重启，一条进度条走完全程。
- 新增「暂不更新」：按版本记在本地，同一个版本不再打扰，出现更新版本时再提示。
- 更新失败时在原位显示原因，并给出「下载安装包手动更新」入口，不再只弹一条会消失的提示。
- 重复点击「立即更新」被拦截，不会并发跑两次自替换。

## 其他改进

- 工具列表统一排序：本机有可用版本的排前面，组内按名称不分大小写排序，已装的不会再被埋在后面。
- 标题栏去掉重复的设置齿轮与作者旁的状态点，设置统一走侧栏入口。

## 问题修复

- 判断某个版本归属哪个版本库改用路径前缀，修复 `D:\store-old` 这类目录被误判成当前版本库的问题；`bin` 目录也不再被重复拼接。
- 目录选择器遇到不存在的默认目录不再直接报错，改为留空让用户自选。
- 打开版本库目录改走统一的目录打开逻辑，路径带空格或中文不再打不开，目录不存在时会自动创建。
- 设置持久化加锁、镜像配置改为写时复制，消除并发保存与本机配置异步序列化时的竞态。

## 升级

v1.3.0 及以后的版本可直接在设置页热更新；更早的版本请下载 `EnvSwitch-Setup-v1.4.0.exe` 覆盖安装。
