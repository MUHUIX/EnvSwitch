# EnvSwitch v1.1.0

工具从 17 款扩到 22 款，补齐系统环境真实探测与自动更新提醒，并把上一轮遗留的安装与交互缺陷一次清完。

## 新增工具

- **pip**：随 Python 解释器分发，只做本机版本识别，切 Python 即同步，不单独安装。
- **nvm-windows**：管理器自身可升级；它装过的 node 版本以只读方式收编，可直接切过去。
- **Git**：采用 MinGit 便携包，解包即得 `cmd\git.exe`，装进版本库后可切换。
- **Docker CLI**：取官方静态 Windows 包（`download.docker.com`），只含 CLI，不含 Docker Desktop。
- **Redis**：Windows 移植版，含 `redis-cli` 与 `redis-server`。

## 界面与交互

- 侧栏按「语言运行时 / 包管理与工具链 / 企业运行时 / 云原生与运维」四组归类，组标题可折叠、带数量气泡，折叠状态本机记忆。
- 设置页改为「自动检查更新」：启动 3 秒后首检，之后每小时静默探测；标题栏与侧栏系统设置按钮出现红点提醒。**只提醒，不自动下载安装**，安装由你在更新面板点「立即更新」决定。
- 全面清理空洞副标题与冗余说明文案，总览健康诊断改为宽屏网格；状态灯补柔和呼吸光晕，卡片悬浮与按钮按压加微动效。
- 「环境诊断」按钮改为滚动到诊断面板；「检索环境」会清缓存后强制复检本机真实环境。
- 修复版本号显示成 `vv1.1.0` 的问题；关于面板授权说明与 `LICENSE` 保持一致（MIT + 附加使用条款）。

## 安装与切换修复

- **托盘菜单**：修复第二个工具的版本项与「开机自启 / 检查更新」菜单项 ID 冲突导致的误触。
- **检查更新按钮**：修复前端调用了不存在的绑定名、点击必定失败的问题。
- **旧配置迁移**：曾经关掉过「启动时检查更新」的用户，升级后不会被默认值重新打开。
- **Git 安装**：改用 MinGit zip，不再因 PortableGit 是 7z 自解压包而装完找不到 `git.exe`。
- **Docker 索引**：改从官方静态目录解析，版本列表不再为空。
- **nvm-windows 索引**：跳过 2.x beta 后仍能正确列出稳定版 1.2.2。
- **Redis 版本号**：完整保留 `5.0.14.1` 这类四段版本号。
- **Maven / Gradle**：修复系统已安装却检测不到的问题（`mvn.cmd` / `gradle.bat`）。
- **系统来源版本**：在详情页与快捷切换中标记为只读，不再给出点了会报错的「切换」按钮。
- **性能**：总览轮询不再每次遍历版本库统计大小、也不再串行拉起二十多个探测进程；托盘菜单只列可切换版本，展开更快。

## 下载

| 文件 | 用途 |
| --- | --- |
| `EnvSwitch-Setup-v1.1.0.exe` | 安装版，per-user 装到 `%LOCALAPPDATA%\Programs\EnvSwitch`，免管理员，装完可选开机自启 |
| `EnvSwitch-win-x64.zip` | 便携版，`EnvSwitch.exe` + `envs.exe` 解压即用 |
| `SHA256SUMS.txt` | 便携包校验值 |
