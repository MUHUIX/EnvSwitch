# EnvSwitch v1.2.0

修掉两个影响日常使用的问题（窗口起不来、版本行重复），把总览页的「快捷切换」弹层重做一遍，并给安装器、侧栏、反馈入口各补了一块。

## 问题修复

- **主界面偶发打不开**：`wails.Run` 之前被放到非主 goroutine，Windows 下会间歇性出现「托盘有图标、双击窗口不出来」。已移回主 goroutine，从根上解决。
- **详情页同一版本显示两行**：系统 PATH 里探测到的版本与已收编进版本库的同一版本重复列出。现在按版本归一后去重，只保留一行，并补了回归测试。

## 总览页「快捷切换」重做

- 弹层不再被裁：下方空间不够时自动朝上展开，右侧放不下时自动改左对齐，长列表内部滚动（最多 264px）。
- 打开弹层时整张卡片抬到兄弟卡片之上，不会再被右边那张卡压住一角。
- 标题区改为「快速切换 + 工具名 + 版本数量」，当前版本左侧加一道 accent 导轨，比整行高亮更好认。
- 条目逐条错峰入场、悬停位移与按压反馈；按钮展开态有明确的高亮与箭头翻转。
- 键盘可达：焦点环补齐；系统来源的只读版本加了悬停说明，写清「不支持快捷切换」；开启「减少动态效果」时入场动画自动关闭。

## 侧栏与设置

- 「网络代理」移到「系统设置」之前，主视图与更新提醒的顺序更符合实际使用频次。
- 折叠把手重做：更小的圆钮 + 更大的点击热区，悬停上色并轻微放大，按下有回弹，键盘聚焦可见。
- 系统设置新增「反馈与需求」板块，一键用默认浏览器打开 GitHub 问题表单。

## 安装器

- 完成页拆成两个独立勾选：**运行 EnvSwitch** 与 **开机自动启动 EnvSwitch**（默认勾选）。之前两者绑在一起，不想自启就只能装完手动去注册表删。

## 反馈

- 仓库新增预设的 Bug 反馈模板（板块、版本、环境、复现步骤分字段填写），设置页「提交反馈」直达该表单。凭证、Token、代理密码请勿粘贴。

## 下载

| 文件 | 用途 |
| --- | --- |
| `EnvSwitch-Setup-v1.2.0.exe` | 安装版，per-user 装到 `%LOCALAPPDATA%\Programs\EnvSwitch`，免管理员，装完可选开机自启 |
| `EnvSwitch-win-x64.zip` | 便携版，`EnvSwitch.exe` + `envs.exe` 解压即用 |
| `SHA256SUMS.txt` | 便携包校验值 |

已有 v1.x 可直接在设置页「软件更新」里热更新，无需手动覆盖安装。
